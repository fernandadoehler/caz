# Caz — protótipo navegável

Protótipo do app de finanças pessoais **Caz** (“galho por galho”), com o mascote castor que reage às finanças do usuário.

O protótipo é um único arquivo (`index.html`), sem dependências: as imagens estão embutidas e as fontes vêm do Google Fonts.

## Como abrir
- Localmente: abra o `index.html` no navegador.
- Online: ative o GitHub Pages em *Settings → Pages*, escolha a branch `main` e a pasta raiz.

## O que dá para testar
- Onboarding, tela inicial com o humor do Caz e o “Ainda posso gastar”.
- Registro de entradas e saídas, cartão de crédito com mês da fatura e parcelamento, estorno.
- Extrato com busca, filtros, edição e exclusão.
- Orçamento mensal, meta de economia, metas com prazo, relatório mensal e anual.
- Conquistas, perfil e configurações.

Os dados são de exemplo e ficam só na memória do navegador.
